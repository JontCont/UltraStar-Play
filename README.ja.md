### 概要

[UltraStar Play](https://usplay.net/) は、無料で利用できるオープンソースの歌唱ゲームです。
音楽に合わせて歌詞と音符を表示し、プレイヤーは歌って得点を獲得します。背景に動画や画像を表示することもできます。

UltraStar Play は [Unity](https://unity.com/) ゲームエンジンで開発されており、主なプログラミング言語は C# です。
上流プロジェクトでは[デスクトップ版とモバイル版](https://github.com/UltraStar-Deluxe/Play/releases)を公開しています。
将来的には tvOS、PlayStation、Xbox など、さらに多くのプラットフォームに対応する可能性があります。

使い始めるには、[プロジェクト Wiki](https://github.com/UltraStar-Deluxe/Play/wiki/First-Steps)をご覧ください。
