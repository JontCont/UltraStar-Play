# UltraStar Play 桌機翻新規格

狀態：已匯入原版程式碼，尚未還原依賴或建置。建立日期：2026-10-24。

## 目標

以現有 UltraStar Play 為基礎翻新桌機體驗，優先使用家中 Windows desktop 執行。沿用唱歌引擎，避免為了介面翻新重做播放、收音與評分。

## 已確認方向

- 主要交付為 Windows 桌機應用程式，不以網站為必要條件。
- 歌曲、譜面、設定與成績以本機儲存為主，不依賴 NAS。
- 優先研究與沿用現有 Unity、C#、UI Toolkit 及 Companion 機制。
- AI 共用規範與 skills 統一放在 `.agents/`，不建立各工具的重複版本。
- 開發必須先讀架構 skill；涉及架構變動時，先建立或更新對應 skill，再實作並驗證。
- 已確認以 commit `a4aaa0b31327062a92d12b5e4cab4d80777f2a3f` 為起點，匯入目前根目錄並保留上游 Git 歷史。

## 本次已交付

- 規格入口、分階段計畫、具相依性的任務清單。
- 有來源與限制說明的上游架構研究基線。
- 共用 AI 指引、開發 skill、架構 skill。
- 已核對來源與 Git 完整性的上游原始碼；原有規劃文件均保留。

本機分支為 `refactor/desktop-refresh`，專案 remote `origin` 為 [JontCont/UltraStar-Play](https://github.com/JontCont/UltraStar-Play)，官方來源保留為 `upstream`。尚未建立本專案提交或推送，也未還原依賴、進行 Unity 建置或實機測試。

## 翻新範圍

候選範圍為主畫面、選歌、演唱畫面、結算與必要設定頁。實際頁面優先順序、視覺風格與互動改動，須經現況盤點與使用者確認後才能進入實作。

預設保留：

- 播放、收音、延遲校正、音準分析與評分行為。
- UltraStar 歌曲格式、既有歌庫、玩家資料與成績相容性。
- 現有輸入方式、在地化與錯誤提示。
- 歌曲編輯器與 Companion 的既有功能；是否一併翻新介面另行確認。

## 非目標

- NAS 部署、完整 Web 版、瀏覽器移植、Electron/Tauri 封裝。
- 為單機模式新增後端、帳號服務、雲端歌庫或雲端評分。
- 重寫唱歌引擎、更動評分規則或自動升級 Unity。
- 預設新增手機點歌、手機音訊擴音、遠端多人遊戲或中文 AI 製譜能力。
- 自動取得或散布未授權歌曲。

## 尚待決定

1. 後續與上游同步的節奏；目前固定在已確認的 commit，不自動合併上游更新。
2. 翻新頁面、視覺方向、目標螢幕與必要輸入裝置。
3. 第一版是否必須支援手機，以及具體是點歌、控制還是麥克風。
4. 最低 Windows 環境、測試硬體與封裝方式。
5. 是否需要 AI 製譜工具；它不是介面翻新的前置條件。

## 驗收原則

- 可在確認的 Windows 環境，以封裝後程式完成選歌、演唱、結算及重新啟動。
- 單機流程在不連 NAS、網站或外部服務時仍可使用。
- 相同譜面及可重現輸入下，評分、時間換算與校正結果符合基線。
- 新介面符合核准的視覺方案，且不遺失既有輸入與錯誤回饋。
- 已有資料不遭破壞；任何必要遷移須先設計備份及驗證。
- 任務、架構文件與 skills 均反映實際交付狀態。
