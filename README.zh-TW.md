### 關於

[UltraStar Play](https://usplay.net/) 是一款免費且開放原始碼的唱歌遊戲。
遊戲會播放音樂、顯示歌詞與音符，也可顯示背景影片或圖片，玩家跟著演唱即可獲得分數。

UltraStar Play 使用 [Unity](https://unity.com/) 遊戲引擎開發，主要程式語言為 C#。
上游提供[桌機與行動裝置版本](https://github.com/UltraStar-Deluxe/Play/releases)。
未來可能加入更多平台，例如 tvOS、PlayStation 與 Xbox。

入門方式請參考[專案 Wiki](https://github.com/UltraStar-Deluxe/Play/wiki/First-Steps)。
