### 关于

[UltraStar Play](https://usplay.net/) 是一款免费且开源的唱歌游戏。
游戏会播放音乐、显示歌词与音符，也可显示背景视频或图片，玩家跟着演唱即可获得分数。

UltraStar Play 使用 [Unity](https://unity.com/) 游戏引擎开发，主要编程语言为 C#。
上游提供[桌面与移动设备版本](https://github.com/UltraStar-Deluxe/Play/releases)。
未来可能加入更多平台，例如 tvOS、PlayStation 与 Xbox。

入门方式请参考[项目 Wiki](https://github.com/UltraStar-Deluxe/Play/wiki/First-Steps)。

这是一个免费且开源的项目，我们欢迎社区成员一起贡献！

欢迎加入 [Discord](https://discord.gg/PAUJFKCGbb)，认识其他维护者；我们会帮助你开始第一次贡献。

你可以通过以下方式支持本项目：

- 在合作的[周边商品商店](https://karaoke.style) 购物

- 通过 [PayPal](https://paypal.me/anstdev) 小额赞助
